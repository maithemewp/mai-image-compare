# Changelog

## 0.2.1 (9/30/26)
* Added: The Mai icon on the Dashboard > Updates screen when Mai Engine is active.

## 0.2.0 (9/30/26)
* Added: A clearer slider handle. It's now a 48px circle with a 2px white border, 2px arrows and a soft shadow, and the divider line is 2px with a shadow, so both stay visible on light and dark photos.
* Added: `--mai-image-compare-handle-*` and `--mai-image-compare-divider-*` CSS custom properties for theming the handle and divider.
* Added: `mai_image_compare_handle` filter to replace the arrows inside the handle with your own markup.
* Changed: The component's `--divider-*` and `--default-handle-*` properties no longer style the block. Use the `--mai-image-compare-*` names instead.

## 0.1.0 (9/21/26)
* Initial release.
